Module: Spinner

Универсальный оверлей с крутящимся колесом. Используется для индикации длительных операций (вычисления, загрузка). 
Поддерживает счётчик ссылок: если несколько операций одновременно
запросили показ спиннера, он скроется только после последней.

Использование:
  import * as Spinner from './Spinner.js';
  Spinner.show();
  try { ... } finally { Spinner.hide(); }

Methods

(static) forceHide()

Принудительно скрыть оверлей и сбросить счётчик. Используется в аварийных ситуациях (например, при необработанной ошибке).

(static) hide()

Скрывает оверлей. Уменьшает внутренний счётчик; оверлей исчезает только при нуле.

(static) show()

Показывает оверлей с крутящимся колесом. Увеличивает внутренний счётчик ссылок.
